REM ============================================================
REM LAB USE ONLY - authorized demo on your own laptop
REM ============================================================
REM What it does: pops a Windows credential prompt styled as
REM "LabGuest WiFi Sign-in" on the sacrificial laptop, then
REM shows ONLY the typed username back on screen to prove the
REM capture. The password is never displayed, stored, or sent.
REM It is discarded by construction: the script never touches
REM the password field of the credential object.
REM
REM Scope: run only on the sacrificial demo laptop, after the
REM authorization gate in docs/competition-live-runbook.md.
REM ============================================================

DELAY 2000
GUI r
DELAY 500
STRING powershell -NoProfile -Command "$c = Get-Credential -Message 'LabGuest WiFi Sign-in'; Add-Type -AssemblyName System.Windows.Forms; [System.Windows.Forms.MessageBox]::Show('LAB DEMO - captured username: ' + $c.UserName + '  (password was discarded, never stored or sent)')"
ENTER
