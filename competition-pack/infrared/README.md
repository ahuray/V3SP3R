# Infrared

`demo_tv_power_TODO.ir` is a placeholder. The only signal is `POWER_DEMO`, a public NEC demo pattern, not a capture from a set in this building. It is here so the pack has a valid infrared file. The manifest target is `/ext/infrared/demo_tv_power_TODO.ir`.

For the live station, learn your own remote and save that capture on the lab SD card. Keep this repository copy as `POWER_DEMO` so the validator can tell the pack file from a private capture.

## Learn your own remote

1. Infrared app → Learn.
2. Point the remote that already controls your TV or projector at the Flipper and press the button you want (Power for this station).
3. Save under `/ext/infrared/` with a name that identifies that set.

## Universal remotes

A universal remote holds many device code sets. Learn from the remote that already works on the equipment in the room so the saved signal matches that set.

## Legality

Own equipment only. Learn and replay remotes for TVs, projectors, and other gear you own. Leave everyone else's equipment alone.
